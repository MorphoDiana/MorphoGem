# MorphoGem 正交多视图拆解规范 (Orthographic Multi-View Decomposition)

本规范定义了将 2D 角色/道具立绘拆解为可直接送入 Tripo 3D 建模节点的四方向正交视图（`front` / `left` / `right` / `back`）与全身比例三视图（`front` / `side` / `back`）的几何与结构标准。

## 1. 输入参考图职责严格分离

当节点接入多张输入参考图时，必须先用读图工具逐张观察，并严格隔离各自职责，严禁属性串染：

- **主立绘 (`source_image`)**：唯一的外观设定源。100% 继承其五官神态、发型分束、服装剪裁、配饰数量与左右不对称细节。
- **画风参考 (`style_ref`)**：仅提取线条粗细、边缘闭合度与赛璐璐/厚涂色彩过渡方式，**严禁**把画风参考图中的服饰、发色或配饰混入当前角色。
- **头身比参考 (`ratio_ref`)**：仅提取头高与总高的比例、四肢修长度与肩胯宽窄比例，**严禁**借用其服装或发型设定。

## 2. 零透视正交投影与「先正后推」顺序

1. **纯平行正交相机 (Zero-Perspective Orthographic)**：
   - 严禁出现近大远小、俯视（大头短腿）或仰视（下巴外翻）。地平线与视线垂直平齐，双耳、双肩、双腕、双踝在同一水平线上。
2. **标准四方向定义与朝向铁律**：
   - `front`（0° 正面）：角色/物件正对镜头。作为全部其余视图的唯一尺寸与结构锚点，**必须最先生成**。
   - `left`（角色自身左侧面）：从角色左手一侧平视，**鼻尖与脚尖朝向画面左方 (`<--`)**。只能看到角色左半身外侧与左发饰。
   - `right` / `side`（角色自身右侧面）：从角色右手一侧平视，**鼻尖与脚尖朝向画面右方 (`-->`)**。只能看到角色右半身外侧与右发饰。
   - `back`（180° 背面）：角色背对镜头。**左右不对称结构必须与 `front` 严格水平镜像**（例如正面画面右侧的发饰/斜挎带，在背面必须位于画面左侧！）。
3. **侧面 T-Pose / A-Pose 手臂防重影规则**：
   - 在 `left` / `right` 侧视图中，T-Pose 手臂沿镜头视线方向正对伸出（呈前缩透视截断面或自然微露手掌），远端手臂被躯干完全遮挡，**严禁在胸前或背后多画出一条向前/向后平伸的手臂**。

## 3. 3D 友好型部件剥离与补全契约

每个 `part_views` 节点只允许绘制其名称指定的单一目标部件，彻底移除其他部件遮挡，并按原设计逻辑合理补全被挡背面与衔接插口：

- **无发裸头/裸脸 (`Head / Bare Face`)**：
  - 100% 剥离全部刘海、鬓角、后发与发饰，补全完整圆润的光头颅顶轮廓、额头与左右双耳；底部在颌下收口，不含衣领与肩膀。
- **独立头发 (`Hair`)**：
  - 彻底挖空面部皮肤、五官、耳朵与颈部躯干，内部呈现干净的中空头壳内壁以便无穿模套入裸头；将 1px 细碎飞丝归纳为有明确块面厚度的闭合发束，防止 3D 网格碎裂。
- **着装身体 (`Clothed Body / Outfit`)**：
  - 剥离头部、长发、手持道具与大型背饰，领口上方保留一段光滑圆柱形脖子作为头部插接桩；完整脑补还原原画中被长发或手臂遮挡的胸口衣襟、腰封与后背花纹；**腋下、袖摆内侧、双腿及两只鞋之间必须留出清晰透明间隙**，防止 3D 重建网格粘连。
- **中空外裙/披风 (`Hollow Skirt / Cape`)**：
  - 仅绘制独立服装外壳，内部彻底挖空腿部与躯干。
- **翅膀/背饰 (`Wings / Backpacks`)**：
  - 成对翅膀在 `front` / `back` 中以水平对称展开绘制，并在 `left` / `right` 侧视图中清晰表现羽毛层叠或机械骨架的真实前后厚度（切勿画成无厚度纸片）。
- **手持武器/独立道具 (`Weapons / Props`)**：
  - 100% 移除握持的手指与人物肢体，补全握柄防滑纹与护手结构；长杆/刀剑主轴必须在画面中心严格 90° 垂直竖立（严禁 45° 斜放），侧面交代剑脊、护手与宝石凸起厚度。
